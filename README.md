# Library Management System

A beginner-friendly Java console application that simulates a Library Management System using Object-Oriented Programming (OOP) concepts.

## Features

* Add a new book
* Display all books
* Search a book by ID
* Issue a book
* Return a book
* Delete a book
* Menu-driven user interface

## OOP Concepts Used

* Classes and Objects
* Constructors
* Encapsulation
* Composition
* Access Specifiers
* Method Reusability
* Arrays of Objects
* `this` Keyword

## How It Works

1. Create a library with a specified capacity.
2. Add books with ID, title, and author details.
3. Manage books through a menu-driven interface.
4. Search, issue, return, and delete books efficiently.
